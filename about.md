# Input Buffer

A small, configurable input buffer for Geometry Dash (Android64, Geode).

## What v0.1 does

If you tap jump in the air just before landing as a cube, the jump happens
when you land. You can turn it off, and set how long before landing a tap
still counts (in milliseconds).

It does **not** change anything in ship, UFO, ball, wave, robot, spider or
swing. There is no predictive behavior in this version.

For testing, a small on-screen message can flash each time a buffered jump
fires (setting: "Show message when buffer fires").
